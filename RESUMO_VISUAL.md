## 📞 Precisa de Ajuda?

### Comum
1. **"Não vejo meus projetos"**
   → F5 (recarregue a página)
   → Verifique admin: /admin

2. **"CV não faz download"**
   → Verifique se arquivo existe em public/
   → Teste direto: /api/download-cv

3. **"Cores não mudaram"**
   → Ctrl+F5 (força reload do cache)
   → Verifique globals.css

4. **"Admin não carrega"**
   → Servidor rodando? (npm run dev)
   → F12 (console) tem erros?

### Referência
→ Leia: TUTORIAL_PRATICO.md (seção Solucionar Problemas)
