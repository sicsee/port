## 📚 Guias Temáticos

### Para Adicionar Projetos
1. Leia: [TUTORIAL_PRATICO.md](TUTORIAL_PRATICO.md) → Seção "Adicionar Seu Primeiro Projeto"
2. Vá para: `http://localhost:3000/admin`
3. Preencha o formulário
4. Clique em "Add"

### Para Customizar Design
1. Leia: [TUTORIAL_PRATICO.md](TUTORIAL_PRATICO.md) → Seção "Customizar Cores"
2. Edite: `src/app/globals.css`
3. Salve e veja as mudanças em tempo real

### Para Atualizar CV
1. Leia: [TUTORIAL_PRATICO.md](TUTORIAL_PRATICO.md) → Seção "Atualizar CV"
2. Coloque seu CV em: `public/cv.pdf` ou `public/cv.txt`
3. Teste em: `http://localhost:3000`

### Para Fazer Deploy
1. Leia: [TUTORIAL_PRATICO.md](TUTORIAL_PRATICO.md) → Seção "Fazer Deploy"
2. Escolha: Vercel (recomendado) ou Netlify
3. Siga as instruções passo a passo

### Para Resolver Problemas
1. Leia: [TUTORIAL_PRATICO.md](TUTORIAL_PRATICO.md) → Seção "Solucionar Problemas"
2. Encontre seu problema
3. Siga o checklist de solução
